# Симуляция дорожного движения на Go

## Запуск

```sh
go run .
```

Открой http://localhost:8080. После изменения Go останови сервер через Ctrl+C и запусти снова. После изменения HTML/JS обнови страницу. Для статики отключён кеш браузера.

```sh
go test ./...
go test -race ./...
go vet ./...
```

## С чего начать читать

1. `main.go` — создание дорог, машин, светофоров и World; запуск таймера и HTTP.
2. `internal/world/world.go` — структура мира и один шаг времени.
3. `internal/world/obstacles.go` — определение свободного расстояния впереди.
4. `internal/car/car.go` — расчёт ускорения, скорости и переход по маршруту.
5. `internal/world/spawn.go` — появление машин.
6. `internal/world/state.go` — снимок состояния, пауза и сброс.
7. `internal/server/server.go` — перевод HTTP-команд в операции мира.

## Один шаг мира

```text
World.Step(dt)
  ├─ updateTrafficLights(dt)
  ├─ updateCars(dt)
  │    ├─ findObstacleAhead(i)
  │    ├─ CalculateAcceleration(obstacle, dt)
  │    ├─ UpdateSpeed(acceleration, dt)
  │    └─ Advance(distance, Roads)
  ├─ removeFinishedCars()
  └─ spawnCars(dt)
```

`dt` — секунды модельного времени. Все машины читают исходное состояние, а результат записывается в `next`. Затем World заменяет слайс целиком. Горутина на каждую машину больше не нужна; расчёт последовательный и не зависит от порядка машин в слайсе.

Светофоры переключаются **до** расчёта машин. Это явное отличие от старого порядка шага.

Путь за шаг рассчитывается через среднюю скорость `(oldSpeed + newSpeed) / 2 * dt`, как раньше. Он ограничивается свободным расстоянием, чтобы машина не пересекала препятствие. В CalculateAcceleration передаётся dt, чтобы не перескочить целевую скорость за один шаг.

## Кто за что отвечает

- **World** знает обо всех объектах, выбирает препятствия и управляет жизненным циклом машин.
- **Car** получает готовый `Obstacle{Distance}`. Машина не знает, вызвано ограничение светофором или другой машиной.
- **Road** хранит геометрию и длину участка.
- **TrafficLight** хранит дорогу, стоп-линию и текущую фазу.
- **Intersection** пока описывает входящие и выходящие дороги. Это данные о соединении, не контроллер проезда.
- **Server** принимает команды и отдаёт независимый снимок мира. Мьютекс общий с таймером; его не держат во время отправки JSON.
- **JavaScript** рисует полученное состояние, не рассчитывает движение.

## Координаты и расстояния

Единицы: метры, секунды, м/с, м/с². Position — передний бампер. Длина машины — `car.Length` (4 м), минимальный зазор — `car.MinGap` (2 м).

`Route: [1, 3]`, `RoadIndex: 1`, `Position: 20` означает: машина на дороге №3, в 20 метрах от её начала.

`Obstacle.Distance` — сколько может пройти передний бампер до допустимой точки остановки. Длина лидера и зазор уже вычтены. Поиск учитывает текущую и следующие дороги маршрута, красные светофоры и конец маршрута.

При переходе с дороги длиной 100 позиция 103 превращается в позицию 3 на следующей дороге. Машина удаляется после последней дороги. Конец маршрута пока считается точкой остановки, как в первоначальной модели.

## Что уже работает

- Разгон и торможение, дистанция до лидера, переходы между дорогами.
- Поиск препятствий независимо от порядка машин; разные ветки маршрута не блокируют друг друга.
- Коллекция светофоров, каждый привязан к своей дороге.
- Генератор чередует настроенные SpawnRoutes; проверяет свободное место на въезде, включая начало следующего участка.
- Пауза, продолжение, повторный сброс к исходным машинам и фазам.
- Независимые копии маршрутов и геометрии в HTTP-снимках.
- Проверка сценария через World.Validate() до запуска.

Сценарий настраивается в main.go. SpawnInterval <= 0 отключает генератор. Он создаёт не более одной машины за шаг; если въезд занят, ждёт освобождения. SpawnRoutes должны быть заданы явно.

## Ограничения и следующий этап

- Одна полоса на дороге, без обгонов и перестроений.
- Маршруты без повторных дорог; совпадающие концы геометрии означают соединение.
- Intersections пока не разрешают конфликты, не резервируют выезд и не задают приоритет.
- Пересечение геометрических линий само по себе не создаёт перекрёсток.
- Одновременное слияние потоков из разных въездов требует отдельного контроллера.
- При позднем красном или большом dt жёсткое ограничение позиции может нарушать плавность торможения; это упрощённая модель.
- Сложность поиска препятствий растёт с числом машин и длиной маршрутов; оптимизацию стоит делать после измерений.

Следующий этап: контроллер одного перекрёстка, проверяющий конфликт направлений и свободный выезд. Перед этим не нужно снова переделывать весь World.

## HTTP

- `GET /state` → `roads`, `cars`, `trafficLights`, `intersections`, `paused`.
- `POST /control` с JSON `{"action":"pause"}`, `resume` или `reset`.
- Reset включает паузу; для движения нажми «Продолжить».

После рефакторинга старые `Light`, `Breaking`, `Car.Update` заменены коллекцией `TrafficLights`, полем `Braking` и отдельными методами машины.
